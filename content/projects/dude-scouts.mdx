Dude Scouts started as a meme, so I suppose we can call it "meme driven development." 

My friends and I had this vision for a place where dudes could learn skills to become better humans and dudes all around.

What started there, ballooned into at least 8 different feature ideas. I went nuts coding just because it was fun.
The main feature has been and will continue to be though: an LMS where memebers of the Dude Scouts can go to learn things!
